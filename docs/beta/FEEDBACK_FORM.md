# StreamSafe: feedback after each session / استبيان بعد كل جلسة

Fill one per session. Send it with the report files from `%LOCALAPPDATA%\StreamSafe\reports` (the `.txt` and `.json`).
عبّي استبيان واحد لكل جلسة، وأرسله مع ملفات التقرير من `%LOCALAPPDATA%\StreamSafe\reports` (ملف `.txt` و`.json`).

## A. Setup / الإعداد

1. Date, and how long you streamed (minutes). / التاريخ ومدة البث بالدقايق.
2. Platform: Twitch / Kick / YouTube. Private test or public? / المنصة، وهل البث تجربة خاصة أو عام؟
3. Setup used: A (OBS -> SRT -> StreamSafe -> platform) or B (window capture). / الطريقة: A أو B.
4. Your graphics card and driver (from the report). / كرت الشاشة (يظهر في التقرير).
5. Game and what you did (story mission, free roam, strip club, beach...). / اللعبة وش سويت فيها.
6. Did `check` give ok / warn / fail? Which lines were not ok? / نتيجة `check` وأي أسطر ما كانت ok.

## B. Safety / الحماية (most important / الأهم)

7. **Did any revealing frame reach viewers (or your recording)?** No / Yes. If yes: time, what was on screen, how long. / **هل وصل أي فريم صريح للمشاهدين أو للتسجيل؟** لا / نعم. لو نعم: الوقت، وش كان، ومدته.
8. Was something covered that did not need it? Time and what. / هل انغطى شي ما كان يحتاج؟ الوقت ووش كان.
9. Was something late or partly covered (a garment slipping, an edge showing)? Time and what. / هل في شي تأخر تغطيته أو انكشف طرفه؟ الوقت ووش كان.
10. Which characters were hard: crowds, far away, fast movement, cutscenes, mods or custom outfits, photo mode? / أي حالات كانت صعبة: زحمة، بعيدين، حركة سريعة، مشاهد سينمائية، مودات، وضع التصوير؟
11. Full-screen cover + mute: did it happen when it should? Too often, too rare, too long? / التغطية الكاملة مع الكتم: هل صارت بوقتها؟ كثيرة، قليلة، أو طويلة؟
12. Did the full-screen slate (not the scene card) appear? When, how long, why do you think? / هل طلعت شاشة التغطية الاحتياطية؟ متى وكم ومن وين تتوقع السبب؟

## C. Performance and stability / الأداء والثبات

13. Did the game keep its normal frame rate? Any stutter? (If the game runs on the same PC.) / هل بقي أداء اللعبة طبيعي؟ فيه تقطيع؟
14. Did the stream to viewers stay smooth? Any buffering or drops? / هل بقي البث للمشاهدين سلس؟ تقطيع أو فصل؟
15. Did StreamSafe crash, freeze, or restart itself? What happened just before? / هل البرنامج وقف أو تجمد أو أعاد التشغيل؟ وش صار قبلها؟
16. Delay: was ~2 s ok? Would you accept less, or more for better safety? Was chat or your voice out of sync? / التأخير: هل ثانيتين مقبول؟ تقبل أقل أو أكثر مقابل حماية أحسن؟ هل الشات أو صوتك طلع غير متزامن؟
17. In setup A: how much does "video only, no sound" block you? / في الطريقة A: كم يعطلك إن البث بدون صوت؟

## D. Use and trust / الاستخدام والثقة

18. How long did install, first run, and OBS setup take? Which step was confusing? / كم أخذ التثبيت وأول تشغيل وإعداد OBS؟ أي خطوة كانت مو واضحة؟
19. Would you trust it on a public stream today? Why or why not? / هل تثق فيه في بث عام اليوم؟ ليش؟
20. What would you need to see before you trust it (e.g., a longer test, a panic key, a preview of what viewers see)? / وش تحتاج تشوف عشان تثق فيه؟
21. Did the viewers or moderators notice anything? / هل لاحظ المشاهدين أو المشرفين شي؟
22. Anything else, and one thing to fix first. / أي ملاحظة ثانية، وأهم شي نصلحه أول.

## E. Attach / المرفقات

- [ ] `session_...txt` and `session_...json` (no images, no stream key; read the `.txt` first) / ملفا التقرير
- [ ] Time list for questions 7-9 / قائمة أوقات الأسئلة 7 إلى 9
- [ ] Optional: a short local clip around a problem time, only if you are comfortable sending it / اختياري: مقطع قصير حول وقت المشكلة لو ترتاح تشاركه
