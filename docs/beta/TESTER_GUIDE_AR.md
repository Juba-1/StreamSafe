# StreamSafe: دليل المختبر (نسخة تجريبية)

النسخة الإنجليزية: `TESTER_GUIDE_EN.md`. شكرًا لأنك تجرّب معنا. هذي نسخة تجريبية، اقرأ ملف `KNOWN_LIMITS.md` أول.

## وش يسوي StreamSafe

البرنامج يقف بين لعبتك وبثك. يأخّر الصورة شوي (ثانيتين افتراضيًا، تغيّرها بـ `--delay`) ويفحص كل فريم خلال هالتأخير.

- أي شخصية لازم تنغطى تاخذ **غطاء صلب** على شكل جسمها، ويتحرك معها.
- المشهد الصريح تنغطى **الشاشة كلها** و**الصوت ينكتم** طول ما الغطاء موجود.
- لو صار أي خلل (خطأ، جهاز بطيء، البرنامج وقف)، المشاهد يشوف شاشة تغطية كاملة. ما يشوف أي فريم ما انفحص.
- **ما فيه تمويه (بلر) ولا بكسلة.** الغطاء دايمًا صلب.

## 1. المتطلبات

| | |
|---|---|
| النظام | ويندوز 10 أو 11 (64 بت) |
| كرت الشاشة | NVIDIA RTX 3060 أو أعلى: الأفضل (الأسرع، يستخدم TensorRT). AMD أو Intel (أي كرت يدعم DirectX 12): مدعوم لكن أبطأ. بدون كرت شاشة: ما يشتغل. |
| ذاكرة الكرت | يُفضّل 6 جيجا أو أكثر (الفحص يحذّرك لو أقل) |
| الرام / القرص | 8 جيجا رام، و2 جيجا فاضية على القرص (الفحص يحذّرك لو أقل) |
| ثاني | برنامج OBS Studio، وFFmpeg (ييجي مع البرنامج)، وحساب على Twitch أو Kick أو YouTube |

شغّل الفحص دايمًا قبل أي شي (الخطوة 3).

## 2. التثبيت

المثبّت **قادم مع المثبّت**: بيثبّت البرنامج وFFmpeg والنماذج وسكربت OBS. إلى أن يجهز، نرسل لك مجلد `StreamSafe`
ومجلد النماذج، والأوامر تحت تشتغل بـ `StreamSafe.exe` من نافذة Command Prompt مفتوحة داخل نفس المجلد.
أي مكان مكتوب فيه `<مجلد النماذج>` حط فيه مسار مجلد النماذج اللي أرسلناه لك.

## 3. أول تشغيل

**3.1 افحص جهازك**

```
StreamSafe.exe check --models "<مجلد النماذج>" --lang ar
```

لو عندك كرت NVIDIA أضف `--engines` عشان تشوف إذا المحركات السريعة جاهزة.

كل سطر نتيجته `ok` أو `warn` أو `fail`، وآخر سطر هو الحكم:

- `ok`: كمّل.
- `warn`: يشتغل لكن فيه نقطة ضعيفة (ذاكرة قليلة، OBS ما انلقى، وضع أبطأ). اقرأ التوصية.
- `fail`: البرنامج **يرفض يشتغل**. أصلحه أول (شوف جدول المشاكل تحت).

**3.2 النماذج.** ملفات النماذج تنفحص كل مرة (لازم تطابق بصمتها). تنزيلها تلقائيًا **قادم مع المثبّت**؛ حاليًا تجي في المجلد اللي نرسله.

**3.3 كروت NVIDIA فقط: تجهيز لمرة وحدة (حوالي 4 دقايق).** TensorRT يبني محركات سريعة لكرتك وتعريفها بالتحديد.
سوّه مرة وحدة قبل أول بث، ويتكرر بعد تحديث تعريف الكرت.

```
StreamSafe.exe prepare --models "<مجلد النماذج>"
```

بيطبع `preparing 1/4 ...` وينتهي بـ `PREPARE_OK`. لو انتهى بـ `PREPARE_FAILED` أرسل لنا النص.
(لو تخطيته البرنامج يشتغل بس على الوضع الأبطأ. كروت AMD وIntel ما تحتاج هالخطوة.)

## 4. طريقتين لربط OBS

استخدم **A** لو تقدر: أبسط، ومفتاح البث ما يطلع من الأمر اللي تكتبه. استخدم **B** لو تحتاج صورة StreamSafe داخل مشهد في OBS أو تحتاج المايك يبقى شغال وقت التغطية.

> **الصوت في الطريقة A:** StreamSafe يمرّر الصوت اللي يرسله OBS (اللعبة + المايك كمزيج واحد)، ويأخّره نفس تأخير
> الصورة بالضبط، فيبقون متزامنين بدون أي ضبط Sync Offset في OBS. وقت التغطية الكاملة ينكتم المزيج كله في A،
> **ومعه المايك** (OBS يرسل مسار صوت واحد مخلوط، و StreamSafe ما يقدر يفصل صوتك عن اللعبة). لو لازم مايكك يبقى
> شغال وقت التغطية استخدم B. الصوت في A جديد: سوّ اختبار التصفيقة على بث خاص وقل لنا في الاستبيان.

### الطريقة A: OBS يرسل لـ StreamSafe (SRT) وStreamSafe يرسل للمنصة

```
OBS ──SRT──> StreamSafe (تأخير + تغطية) ──RTMPS──> Twitch / Kick / YouTube
```

1. جهّز مشهدك في OBS مثل العادة.
2. خذ من منصتك **رابط السيرفر** و**مفتاح البث** (Twitch: لوحة المنشئ، Kick: إعدادات البث، YouTube: الاستوديو ثم Go live). اجمعهم بالشكل `السيرفر/المفتاح`.
   شكل المثال: `rtmps://<سيرفر-البث>/app/<مفتاحك>`. استخدم عنوان `rtmps://` اللي تعطيك إياه المنصة.
3. افتح Command Prompt داخل مجلد StreamSafe وشغّل StreamSafe **أول**. بيبقى ينتظر OBS:
   ```
   StreamSafe.exe run --input "srt://127.0.0.1:9000?mode=listener" --output "rtmps://<سيرفر-البث>/app/<مفتاحك>" --delay 2
   ```
4. في OBS: **Settings -> Stream**، الخدمة **Custom**، السيرفر `srt://127.0.0.1:9000`، واترك Stream Key فاضي. الترميز H.264 مثل العادة. اضغط OK.
5. اضغط **Start Streaming** في OBS. الحين OBS يرسل لـ StreamSafe، **مو** للمنصة.
6. افتح صفحة بثك في المنصة. بعد مدة التأخير بتشوف صورتك. معاينة OBS **بدون** تأخير: أنت تلعب على الصورة المباشرة، والمشاهد يشوف الصورة المحمية.
7. للإيقاف: اضغط Stop Streaming في OBS وخلّ StreamSafe ينتهي لوحده (شوف "إنهاء الجلسة" تحت).

ليش A آمنة: OBS ما عنده مفتاح البث، ولو StreamSafe وقف ما يطلع شي للمنصة. اللعبة الخام ما تطلع أبدًا.
تنبيه: المفتاح مكتوب داخل الأمر، فلا تصوّر نافذة Command Prompt ولا ترسل الأمر لأحد.

### الطريقة B: StreamSafe يعرض الصورة في نافذة وOBS يلتقطها

تحتاج شغل أكثر في OBS، لكنها تحمل الصوت وتخلي مفتاح البث عند OBS.

```
التقاط اللعبة (مشهد مخفي "Game Raw")  ->  OBS Virtual Camera  ->  StreamSafe  ->  نافذة "StreamSafe Output"
                                       ->  مشهد البث في OBS يلتقط النافذة  ->  المنصة
```

1. **المشهد المخفي.** سوّ مشهد اسمه `Game Raw` فيه التقاط اللعبة، وسمّ المصدر `Game Raw`. لا تضيف هذا الفيديو لمشهد البث أبدًا.
2. **صوت اللعبة مصدر لحاله.** أضف **Audio Input Capture** (أو Audio Output Capture) واسمه `Game Audio`.
3. **الكاميرا الافتراضية.** اضغط **Start Virtual Camera** (من Controls، وعجلة الإعدادات جنبه): Output Type **Source**، والمصدر **Game Raw**. مو "Program".
4. **شغّل StreamSafe** (حدد ملف الحالة أول، والمسار لازم بحروف إنجليزية فقط):
   ```
   mkdir C:\ProgramData\StreamSafe
   set OBS_STATE=C:\ProgramData\StreamSafe\state.txt
   StreamSafe.exe run --input "device:OBS Virtual Camera" --output window --delay 2
   ```
   بتفتح نافذة اسمها `StreamSafe Output`. لا تسكّرها ولا تصغّرها (لو صغّرتها البرنامج يرجّعها).
5. **مشهد البث** واسمه `StreamSafe Stream`:
   - **Window Capture** لنافذة `StreamSafe Output` بكامل الشاشة.
   - مصدر صورة اسمه `StreamSafe Slate` فوق كل شي، والعين **مقفولة** (السكربت يفتحه وقت الحاجة).
   - `Game Audio`: **Advanced Audio Properties -> Sync Offset** = 2000 ms (نفس التأخير).
   - المايك: Sync Offset = 2000 ms برضو. الكاميرا: فلتر **Video Delay (Async)** = 2000 ms.
   - هذي الأرقام بداية. سوّ اختبار التصفيق (صفّق قدام الكاميرا، شغّل صفارة في اللعبة، سجّل، وتأكد إنها الثلاثة متطابقة) وعدّل.
6. **سكربت الحماية.** OBS -> **Tools -> Scripts -> +** -> اختر `streamsafe_guard.lua` (مكان الملف: **قادم مع المثبّت**؛ حاليًا نرسله لك). عبّي: ملف الحالة `C:\ProgramData\StreamSafe\state.txt`؛ صوت اللعبة `Game Audio`؛ الشريحة `StreamSafe Slate`؛ المخرج `StreamSafe Output`؛ الفيديو الخام `Game Raw`؛ المشهد المحمي `StreamSafe Stream`؛ وقت التجمد `500`.
   السكربت يكتم اللعبة ويعرض شاشة التغطية خلال نص ثانية لو StreamSafe وقف أو تجمد أو النافذة فضت.
7. **زر الطوارئ.** OBS -> Settings -> Hotkeys -> "StreamSafe: PANIC (cover everything)": حط له زر. ضغطة وحدة = تغطية وكتم، وضغطة ثانية تلغيها.
8. ابث من OBS للمنصة مثل العادة بمشهد `StreamSafe Stream`. **جرّب أول على بث خاص أو غير مدرج.**
9. اختبار سريع قبل البث الحقيقي: اقتل StreamSafe من Task Manager. لازم تطلع شاشة التغطية واللعبة تنكتم خلال ثانية.

## 5. التأخير

- المشاهدين يشوفونك متأخر حوالي ثانيتين عن الوقت الحقيقي (غير تأخير المنصة نفسها). بهالطريقة البرنامج يلحق يفحص كل فريم.
- **الشات بيحسّونه متأخر.** تشوف رد الشات على شي شافه المشاهد قبل ثانيتين أو أكثر. نبّه مشاهديك.
- في الطريقة B لازم المايك والكاميرا ينتأخرون نفس المقدار (الخطوة 5)، وإلا صوتك بيسبق اللعبة.
- تقدر تغيّره بـ `--delay <ثواني>`. التأخير الأقصر يعطي الجهاز وقت أقل وممكن يزيد التغطية الكاملة (جهاز بطيء). جرّب الافتراضي أول.

## 6. تغطية الشاشة كاملة وكتم الصوت شي طبيعي

لما StreamSafe يشوف مشهد صريح، يغطي **الشاشة كلها** ببطاقة و**يكتم اللعبة**. هذا السلوك المقصود، مو عطل.
وبعد يطلع شاشة التغطية لحظة عند البداية، ولما يصير خلل أو بطء. في الطريقة B المايك يبقى شغال؛ في الطريقة A المايك ينكتم مع اللعبة طول ما التغطية موجودة (شوف الملاحظة في القسم 4). وإذا خلص المشهد ترجع الصورة والصوت لوحدهم.

## 7. لو غطّى زيادة أو غطّى ناقص

ما فيه إعداد تغيّره في النسخة التجريبية، ولا تحاول تضبطه. بدل كذا:

1. **غطّى زيادة** (غطى شخصية أو شاشة عادية) أو **غطّى ناقص / متأخر** (طلع شي كان لازم ينغطى): سجّل **الوقت** (وقت البث أو ساعتك) ووش كان على الشاشة. **لو فريم صريح فعلًا وصل للمشاهدين، قل لنا فورًا ولا تنتظر الاستبيان.**
2. لو سجّلت البث عندك، احتفظ بالتسجيل؛ ممكن نطلب منك مقطع قصير حول ذاك الوقت.
3. اكتبها في الاستبيان مع الوقت. هذي أنفع معلومة تقدر ترسلها.

## 8. إنهاء الجلسة وإرسال التقرير

عند الإنهاء الطبيعي، StreamSafe يكتب تقرير قصير في:

```
%LOCALAPPDATA%\StreamSafe\reports
```

(الصق هذا المسار في شريط العنوان في مستكشف الملفات.) ويطبع `SESSION_REPORT <المسار>` لما يخلص. بتلقى ملفين بنفس الاسم: `session_YYYYMMDD_HHMMSS.txt` (اقرأه، فيه عربي وإنجليزي) و`.json`.

**مهم:** لو أوقفت StreamSafe بـ **Ctrl+C** ما يُكتب تقرير في هالنسخة. خلّه ينتهي لوحده: أنهِ البث أو الإدخال
(في الطريقة A اضغط Stop Streaming في OBS؛ المفروض StreamSafe ينتهي لما OBS يوقف الإرسال. لو ما انتهى بعد دقيقة قل لنا، ثم استخدم Ctrl+C وأخبرنا إنه ما انكتب تقرير).

للإرسال: أرفق ملفي `.txt` و`.json` لكل جلسة مع رسالتك والاستبيان (`FEEDBACK_FORM.md`).
سطر النتيجة يقول `ok` أو `check`؛ أرسله في الحالتين.

**الخصوصية.** التقرير فيه أرقام وأوقات فقط: اسم كرت الشاشة، نسخة ويندوز، مدة البث، كم ثانية تغطية وكتم، وعدد الأخطاء.
**ما فيه صور، ولا رابط البث أو مفتاحه، ولا مسارات ملفات.** الأمر اللي كتبته مو داخله.
افتح ملف `.txt` واقرأه قبل ما ترسله.

## 9. حل المشاكل (من نتيجة `StreamSafe.exe check`)

| السطر في الفحص | المعنى | وش تسوي |
|---|---|---|
| `gpu` FAIL | ما لقينا كرت شاشة | ثبّت آخر تعريف (NVIDIA / AMD / Intel) وأعد الفحص |
| `gpu` WARN | ذاكرة الكرت أقل من 6 جيجا | سكّر البرامج الثانية وقت البث، وقل لنا نوع كرتك |
| `runtime` FAIL | البرنامج ما يقدر يستخدم الكرت، أو ملفات ناقصة | حدّث تعريف الكرت وويندوز؛ لو بقت المشكلة أعد التثبيت |
| `runtime` WARN (DirectML على NVIDIA) | يشتغل لكن أبطأ من وضع NVIDIA | استخدم نسخة NVIDIA وشغّل `prepare` |
| `ffmpeg` FAIL | ملف FFmpeg ناقص | أعد تثبيت البرنامج |
| `models` FAIL | ملفات النماذج ناقصة أو تالفة | انسخ مجلد النماذج من جديد / أعد التثبيت |
| `python` FAIL | المحرك الداخلي قديم | أعد التثبيت من النسخة الرسمية |
| `os` WARN | النظام مو ويندوز | البث المباشر مدعوم على ويندوز فقط |
| `obs` WARN | OBS مو في مكانه المعتاد | ثبّت OBS، أو تجاهلها لو مثبّت في مكان ثاني |
| `ram` / `disk` WARN | رام أو مساحة قليلة | سكّر البرامج / فضّي مساحة |
| `engines` WARN | محركات NVIDIA السريعة مو جاهزة | شغّل `StreamSafe.exe prepare --models "<مجلد النماذج>"` |

مشاكل ثانية:

| المشكلة | وش تسوي |
|---|---|
| البث كله شاشة تغطية | شوف نافذة Command Prompt إذا فيها أخطاء. الجهاز البطيء يسبب هذا: سكّر البرامج الثانية وقل لنا نوع كرتك |
| ما يوصل شي في الطريقة A | شغّل StreamSafe **قبل** OBS. تأكد من `srt://127.0.0.1:9000` في OBS (بدون مفتاح) وإن الأمر فيه `?mode=listener` |
| ما يوصل شي للمنصة | تأكد من السيرفر والمفتاح، وإن منصتك تقبل `rtmps://` |
| ما فيه صوت في الطريقة A | تأكد إن OBS نفسه فيه صوت (أعمدة الميكسر تتحرك) وإنك على آخر نسخة من StreamSafe. السكوت وقت التغطية الكاملة ونص ثانية تقريبًا بعدها مقصود |
| نافذة `StreamSafe Output` ما تظهر في OBS | StreamSafe لازم يكون شغال أول؛ استخدم Window Capture واختارها من القائمة |
| شاشة التغطية عالقة بعد إعادة تشغيل StreamSafe (B) | تأكد إن مسار ملف الحالة `C:\ProgramData\StreamSafe\state.txt` وبحروف إنجليزية |

رموز خروج `check`: 0 = تمام، 1 = تحذيرات، 2 = فشل.
