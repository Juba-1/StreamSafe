StreamSafe - third-party software and models
=============================================

StreamSafe covers risky characters in a game stream before viewers see them. It uses the following third-party
components. Each keeps its own licence; the full texts are in the "licenses" folder next to this file.

MODELS (downloaded on first run, checked against a list of sha256 values; or loaded from a file we send you)

  C-RADIOv4-H (NVIDIA) and the ONNX export made from it - the "eye" (who must be covered)
      Licensed by NVIDIA Corporation under the NVIDIA Open Model License.
      Licence text: NVIDIA-Open-Model-License.txt
  RF-DETR-Seg (Roboflow)            - person detector and masks              - Apache-2.0 (Apache-2.0.txt)
  SigLIP 2 (Google)                 - scene model                            - Apache-2.0 (Apache-2.0.txt)
  ViTPose (usyd-community)          - pose                                   - Apache-2.0 (Apache-2.0.txt)

  The risk heads (small decision files on top of the eye) are ours.

PROGRAM LIBRARIES (inside the program folder)

  ONNX Runtime (Microsoft, MIT, with DirectML)        ONNX-Runtime-MIT.txt
  FFmpeg (LGPL build, shared libraries)               ffmpeg\LICENSE.txt (GNU LGPL version 3)
      The build contains no GPL or non-free components (no libx264). The libraries are separate DLL files in
      the "ffmpeg\bin" folder and may be replaced by your own LGPL build of FFmpeg.
      Source code of this FFmpeg: https://ffmpeg.org/releases/ (version 8.1.3); the build scripts:
      https://github.com/BtbN/FFmpeg-Builds . We will send the exact source on request.
  OpenCV (Apache-2.0; its own FFmpeg libraries are LGPL)  Apache-2.0.txt
  Python (PSF licence), NumPy (BSD), Pillow (HPND), Tcl/Tk (BSD-style)   Python-PSF.txt

OPTIONAL, DOWNLOADED ONLY IF YOU SAY YES (fast mode for NVIDIA cards)

  NVIDIA CUDA, cuDNN and TensorRT libraries are downloaded from NVIDIA's own package servers to your PC when you
  enable the fast NVIDIA mode. They are NOT part of this installer. Their licences are NVIDIA's:
  https://docs.nvidia.com/deeplearning/tensorrt/latest/reference/sla.html
  https://docs.nvidia.com/cuda/eula/index.html
  https://docs.nvidia.com/deeplearning/cudnn/latest/reference/eula.html

This program does not contain or use AGPL code, and no model with research-only weights.
